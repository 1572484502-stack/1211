# 视界工坊（Vista Studio）

本地智能影音创作工作台。当前版本提供“智能音乐重编排”。

## 直接运行

Windows 用户双击 `启动视界工坊.cmd`。启动器会在 `127.0.0.1` 拉起轻量本地服务，再以 Microsoft Edge 独立应用窗口打开。音乐处理在本机完成。

## 当前功能

- 拖放或选择 MP3、WAV、M4A、AAC、FLAC、OGG 音频。
- 两步式工作流：先做段落分析，再进入时长重塑。
- 浅色结构分析面板：BPM、时长、小节估计、声道、分段波形与可点击结构色带。
- 可手动选择前奏、主歌、高潮、尾奏等段落；未选中的段落不会进入重编排范围。
- 设置任意目标时长，支持快捷预设。
- 本地估计 BPM、节拍与小节能量。
- 一次生成方案 A、B、C 三个候选版本，不附加风格名称。
- 采用完整小节切割、整拍等功率交叉衔接、接点响度匹配和切点过零修正，降低断拍与爆音感。
- 每个候选方案用双层波形显示原曲取段、舍弃范围、拼接顺序与衔接点。
- 波形包含实时播放头，可点击或拖动跳转到任意位置并立即试听，也支持键盘左右键微调。
- 切换“段落分析/时长重塑”会自动暂停；原曲和方案 A/B/C 始终只允许一个音频播放。
- 在普通节拍之外估计强拍位置，以 4/8 小节乐句组织结构，并按“开头—发展—核心—收尾”的顺序生成候选。
- 试听每个方案，查看采用的原曲片段并导出 WAV。
- 本地保存最近 20 条生成任务信息，可从“历史记录”抽屉查看或清空。
- 不上传素材，不需要 API Key。
- 不包含会员订阅、积分付费或音乐混合功能。

## 模块化原则

软件采用轻量“外壳 + 独立功能模块”结构。音乐和后续功能分别维护自己的界面、状态、算法与样式，只通过公共的功能生命周期、媒体会话和命名空间存储接口通信。新增或修改某个功能时，不直接引用其他功能目录。详细约束见 `ARCHITECTURE.md`。

## 桌面开发模式

项目已包含 Electron 外壳。完成 Electron 运行时安装后可执行：

```powershell
pnpm start
```

## 当前版本边界

这是第一阶段 MVP。它使用节拍、响度和小节能量进行重排，对节奏清楚的流行乐、电子乐和配乐效果更稳定；暂未理解歌词语义，也未进行人声/伴奏分轨。后续版本会加入更强的段落识别、歌词连续性检查与人工微调时间线。
